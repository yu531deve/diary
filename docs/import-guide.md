# import/ 取り込みガイド

`import/` に置かれた既存原稿（Yu が過去に作成した院試問題集）を Diary の正規形（`content/{id}/`）に変換するための手順書。**この文書自体は調査・文書化のみを目的とし、`content/` と `import/` の中身は変更しない**（issue #126）。

実際の取り込み作業（issue #57 の子issue、1 問または少数単位で行う想定）を行う人向けに、`import/` の実物を見て判明した具体的な変換方法を記す。一般的な LaTeX 変換の作法ではなく、**このリポジトリの `import/` に実際にあるファイルに即した**内容である。

## 2. 1 問あたりの変換手順

**粒度は 1 問 = 1 記事（個別 ID）に確定している**（issue #168 / Yu 確定事項 1）。1 テーマ内の `\shomon{問1.}` `\shomon{問2.}` … は、それぞれ独立した `content/{id}/` に分割する。1 テーマにまとめない理由は、テーマ内の小問は難易度が異なる独立した類題であり（例: `01_ベルヌーイ型微分方程式` は問 1・問 2 が標準、問 3 は初期値条件付きで一段上）、まとめると `difficulty` を 1 つしか持てず関連問題機能（#109）も働かなくなるため。

1. **ID 採番のタイミング**: **そのテーマが 1 章の一覧表で Yu により「採否」= `◯` と判定された後にのみ**、承認されたテーマ内の各問題に対して ID を振る（issue #168 / Yu 確定事項 2）。未採択・保留のテーマの問題に先回りして ID を消費しない。採番自体は `content/` の既存最大 4 桁 ID + 1（`/new-problem` コマンドで雛形生成可）。振り直し・欠番の詰め直しはしない。
2. **`content/{id}/` に配置**: 分割した問題 1 問ごとに `meta.yaml` / `problem.tex` / `solution.tex` の 3 ファイルを作成。
3. **本文のみ形式への書き換え**（詳細は 3 章の対応表）:
   - `\documentclass`〜`\begin{document}` の preamble 一式を削除。
   - `\kamokumei{...}` は削除（Diary 側は `\diarytitle{id}{title}` で見出しを出す。ページ全体の科目見出しは不要）。
   - `problem.tex` の先頭に `\diarytitle{{id}}{{title}}` を追加。
   - `\shijibun{...}`（導入文）は問題文冒頭に統合する。ただし**解法そのものを示すヒントが含まれる場合は、その部分だけ問題文から外して解答側へ移す**（次項「ヒントの扱い」を参照）。
   - `\shomon{問N.}{...}` は該当する 1 問だけを抜き出し、`problem.tex` の本文にする（enumerate 化はしない。1 テーマ = 複数の独立した問題として、小問ごとに個別の `content/{id}/` を作る）。
   - `answers.tex` の `\daimon{...}`（解法のまとめ見出し）は解答冒頭の解説文として残せる。
   - `\begin{mondaiboxS}{問N}...\end{mondaiboxS}`（問題文の再掲ボックス）は Diary 側に同等の環境がないため削除し、`solution.tex` は地の文から始める（`problem.tex` に既に問題文があるため再掲は本来不要）。
   - `\kaitou` 見出しはそのまま `\textbf{}` 等の地の文にするか削除して解答本文をそのまま続ける。
   - `\clearpage` は複数問を 1 ファイルに収める際の区切りとしてのみ必要なら残すが、Diary の 1 問 1 ファイル構成では通常不要になる。
4. **指示文のヒントを解答側へ移す**（issue #168 / Yu 確定事項 4）: `\shijibun{...}` に含まれる「（ヒント: ...）」のような一文が、置換や変形の**解法そのもの**を明かしている場合、そのヒント部分は問題文に残さず解答側（`solution.tex` の冒頭）に移す。院試問題として、解法を問題文で先出ししてしまうのは不適切なため。

   **具体例（`import/01_分野別類題/01_ベルヌーイ型微分方程式/problems.tex`）**:

   Before（`import/` 側、ヒントが問題文に混在）:
   ```latex
   \shijibun{次の常微分方程式を解き、導出過程を示せ。（ヒント: $y' + P(x)y = Q(x)y^{n}$ の形の方程式は、$u = y^{1-n}$ の置換により線形方程式に帰着できる。）}

   \shomon{問1.}{次の常微分方程式の一般解を求めよ（$y$ を $x$ を用いて表せ）。}
   \[
   \frac{dy}{dx} + \frac{y}{x} = x\,y^{2}
   \]
   ```

   After（`content/{id}/problem.tex`、ヒントを除いた指示文のみ）:
   ```latex
   \diarytitle{{id}}{{title}}

   次の常微分方程式の一般解を求め、導出過程を示せ（$y$ を $x$ を用いて表せ）。
   \[
   \frac{dy}{dx} + \frac{y}{x} = x\,y^{2}
   \]
   ```

   After（`content/{id}/solution.tex`、外したヒントを冒頭に移設）:
   ```latex
   この方程式は $y' + P(x)y = Q(x)y^{n}$ の形（ベルヌーイ型）であり、$u = y^{1-n}$ の置換により線形方程式に帰着できる。

   $n = 2$ のベルヌーイ型。両辺を $y^{2}$ で割ると
   \[
   y^{-2}\frac{dy}{dx} + \frac{1}{x}\,y^{-1} = x
   \]
   ...（以下 answers.tex の解法をそのまま続ける）
   ```

   問 2・問 3 も同じ `\shijibun{}` を共有しているため、3 問すべての `problem.tex` からヒント文を除き、各 `solution.tex` の冒頭にそれぞれ同じヒント文を移設する。
5. **`meta.yaml` 起票**: `field.major` / `field.minor` は 1 章の表を参考に仮付けし、`tags.yaml` にある値のみ使用（無ければ追加提案を PR コメントに書き、辞書追加は別 issue）。`difficulty` は `docs/difficulty.md` 基準で暫定値、**`status: draft` 固定（`published` は Yu のみが後から付ける。issue #168 / Yu 確定事項 3）**。
6. **`make lint` / `make pdf` / `make html` を確認**（Definition of Done の 4 点）。
7. **`import/` から取り込んだ元ファイル（テーマフォルダ全体、または処理済みの元テキスト部分）を削除**。1 テーマ内の一部の問題だけ取り込んだ場合、残りの問題を含む元ファイルをどう扱うか（フォルダごと削除するか、取り込んだ小問だけ除去するか）は Yu に確認する。

## 3. 頻出パターンの書き換え対応表

| import/ 側の記法 | 対応 | 備考 |
|---|---|---|
| `\documentclass[a4paper,11pt]{article}` 〜 `\usepackage{shoakubox}` | 削除 | ビルド側が `diary.sty`（`jlreq` + `lualatex`）を適用するため本文のみ書く |
| `\begin{document}` / `\end{document}` | 削除 | 同上 |
| `\kamokumei{...}` | 削除、または `problem.tex` 冒頭の `\diarytitle{id}{title}` に統合 | Diary は `\diarytitle` が見出しを兼ねる |
| `\shijibun{...}` | 地の文として残す | マクロ定義なしでも普通の段落として機能する内容なので `\shijibun{}` を外して中身だけ残す |
| `\shomon{問N.}{text}` + 続く `\[ ... \]` | `\begin{enumerate}\item text \[ ... \] \end{enumerate}` に展開、または該当小問のみ抜粋 | 1 テーマ=複数問という単位の違いに注意（要 Yu 判断） |
| `\daimon{...}` | 解答冒頭の説明文として残す（マクロ除去） | 見出しの強調が欲しければ `\textbf{}` に置換 |
| `\begin{mondaiboxS}{...}...\end{mondaiboxS}` | 削除（中身の問題文再掲は不要。図表や強調が必要なら `\textbf{}`/`\begin{quote}` 等 amsmath 標準機能で代替） | `shoakubox.sty`（`tcolorbox` 依存）は Diary に存在せず、`\usepackage` 自体が lint で禁止 |
| `\kaitou` | 削除、または `\textbf{解答}\par` 等プレーンな強調に置換 | マクロ定義がないため必ず除去 or 代替が必要 |
| `\clearpage` | 基本削除（1 問 1 ファイルなので改ページ制御は不要） | 複数小問を 1 ファイルにまとめる場合のみ検討 |
| `\bm{...}`（25, 28, 38 番テーマで使用） | そのまま使用可（変換不要） | `bm` パッケージは `styles/diary.sty` に追加済み（または追加予定、別 issue）。`\mathbf` への置換は行わない（issue #168 / Yu 確定事項 5） |
| `\usepackage{preamble}` / `\usepackage{shoakubox}` | 完全に削除 | `usepackage` は禁止コマンド。仮に preamble.sty 相当の機能が必要でも `content/` 側からは呼べない |
| `TEXINPUTS=...` を使ったコンパイルコメント行（`% コンパイル: ...`） | 削除 | Diary のビルドは `make pdf` / `make html` に統一されており無関係 |
| `\begin{pmatrix}` / `\begin{vmatrix}` / `\begin{align*}` / `\begin{cases}` / `\begin{aligned}` | そのまま使用可 | `amsmath` は `diary.sty` が読み込み済み |
| `\frac`, `\int`, `\sum`, `\lambda` 等の基本記法 | そのまま使用可 | `amsmath` / `amssymb` の範囲内 |
| TikZ 図 | 該当なし（`import/` の 38 テーマに図は存在しない） | もし今後 TikZ を含む原稿が追加された場合は `diary.sty` が `tikz`（`calc, intersections`）を読み込み済みなのでそのまま使えるが、独自 tikzlibrary が必要なら要相談 |

`lint/forbidden-commands.yaml` で禁止されているのは `write18` / `input` / `include` / `usepackage` の 4 つ。`import/` の原稿では `\usepackage` のみが該当し、これは preamble 削除の過程で自然に取り除かれる。`write18` / `input` / `include` の使用は 38 テーマ中どこにも見られなかった。

## 4. 詰まりやすい箇所・Yu に確認すべき事項

以下のうち **1・2・3・5 は issue #168（2026-08-08、issue #57 の Yu 判断）で確定済み**。残りは取り込み作業の中で都度確認する。

1. **粒度**: ~~不一致~~ → **確定**。1 問 = 1 記事（個別 ID）。1 テーマにまとめない（2 章参照）。
2. **採番タイミング**: **確定**。テーマ単位で Yu が採否を決めた後、承認されたテーマの問題にのみ ID を振る（1 章の表の「採否」列・2 章参照）。
3. **`status`**: **確定**。全問題 `status: draft` で取り込む。`published` は Yu のみが後から付ける。
4. **指示文のヒント**: **確定**。ヒントが解法そのものを明かしている場合は問題文から外し、解答側へ移す（2 章の具体例参照）。
5. **`\bm`（太字ベクトル）**: **確定**。25 対角化・28 最小二乗法・38 線積分の 3 テーマで使用。`styles/diary.sty` に `bm` パッケージを追加して対応する（別 issue）。`\mathbf` への置換は行わない。
6. **問題文の再掲（`mondaiboxS`）の要否**: `answers.tex` は問題文をボックスで再掲してから解答する構成。Diary の `/solutions/{id}/` ページでは `problem.tex` と並べて表示される設計かどうかに依存するため、再掲を残すか削るかは site 側の仕様（`site/CLAUDE.md`・`docs/requirements.md`）と合わせて Yu が判断する。
7. **難易度判定**: 大学院入試の計算問題であり、`docs/difficulty.md` の想定利用者（大学受験生・国公立二次〜最難関大二次）の基準とは前提とする層が異なる。1 章の表の値はあくまで暫定であり、**院試レベルの原稿を Diary にそのまま載せてよいかという「レベル適合性」自体の判断も含めて Yu が行う**（README.md にも同旨の注記あり）。
