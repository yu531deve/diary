# 難易度基準（5 段階）

- 版: v1.0（Yu 確定 2026-08-07）
- `meta.yaml` の `difficulty`（1〜5 の整数）はこの基準に従う。linter は値域を強制する

| 段階 | 基準 |
|------|------|
| 1 | 教科書の章末レベル。定義が分かっていれば解ける |
| 2 | 共通テスト〜標準私大レベル |
| 3 | 標準的な国公立二次で完答が期待される |
| 4 | 難関大二次。部分点は取れるが完答は上位層 |
| 5 | 最難関大の難問。捨て問判断も戦略のうち |

## 運用メモ

- 判定軸は「どの層の受験生が、試験時間内に**完答**できるか」
- 計算量だけが重い問題は、発想が典型なら段階を上げすぎない（+1 まで）
- 小問誘導が丁寧な場合は、誘導込みの実質難度で判定する
