# 難易度基準（5 段階）

初版は標準的な入試レベル区分に基づく（2026-08-04 Claude 作成）。運用しながら編集してよい。
判定は「どの層の受験生が、試験時間内に完答できるか」を軸にする。複数段階に跨がると感じたら、**完答**に必要な力で判定する。

| 段階 | 基準文 |
|------|--------|
| 1 | 教科書の例題・章末問題レベル。定義と基本公式を 1 つ適用すれば解ける。共通テストの序盤設問相当。標準的な受験生が数分で完答できる |
| 2 | 入試基礎レベル。典型パターンの一段適用で、方針選択に迷いがない。共通テスト中盤〜地方国公立・日東駒専の易しめの大問相当。基礎が固まっていれば完答できる |
| 3 | 標準的な国公立二次・MARCH レベルで完答が期待される。複数の典型手法の組み合わせ、または一段の工夫を要する。合否を分ける標準問題 |
| 4 | 難関大（旧帝大・早慶）レベル。方針が一目では立たず、適切な設定・場合分け・計算の見通しなど複数の関門がある。完答者は受験者の少数派で、部分点勝負になりやすい |
| 5 | 最難関レベル。東大・京大の難問セットや後期日程相当。非典型で、発想の転換や重い議論・計算を要する。合格者でも完答は稀で、捨て問と判断されうる |

## 運用メモ

- 想定は「その大学を志望する受験生」ではなく**受験生全体**の分布。段階 3 が山の中心になる想定
- 計算量だけが重い問題は、発想が典型なら段階を上げすぎない（+1 まで）
- 小問誘導が丁寧な場合は、誘導込みの実質難度で判定する
