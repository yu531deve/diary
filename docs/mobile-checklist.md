# モバイル実機チェックリスト

Diary サイトのモバイル表示・挙動を実機で確認するためのチェックリスト。issue #111（#125 で新設、#111 で表形式に再整備・項目追加）。
PR のマージ前後、または関連実装の変更時に Yu が実機で辿る。**初回実施は本チェックリスト整備の対象外であり、Yu の実機作業として別途行う。**

対象実装は主に以下:

- `site/src/components/BottomTabNav.astro`（下部タブナビ、`max-width: 860px` で表示）
- `site/src/pages/index.astro`（トップページ: モバイルもデスクトップと同じ `#track` のスクロール駆動演出。7 シーン構成）
- `site/src/pages/problems/[id]/index.astro`（`.mobile-action-bar`: 固定アクションバー、`DifficultyBadge`、OGP メタタグ）
- `site/src/components/SearchModal.astro`（⌘K 相当のモバイル検索モーダル）
- `site/src/lib/save-store.ts` / `site/src/pages/save/index.astro`（保存機能、正常系・エラー表示、#253）
- `site/src/components/DifficultyBadge.astro`（難易度バッジ、#131）
- `site/src/components/SiteHead.astro`（OGP メタタグ、#123）

対象端末: **iOS Safari** と **Android Chrome** の両方で、下記項目をひととおり実施する。「対象」列が「両方」以外の項目は、指定端末側を優先して確認する。

## 4. トップページのアニメーション（収束アニメ・7 シーン スクロール、`#track`）

| # | 対象 | 検証手順 | 期待結果 |
|---|------|----------|----------|
| 4-1 | 両方 | 画面幅 860px 以下でトップページを開く | 初回ローディングの収束アニメ（Diary の文字形へ収束）が表示される |
| 4-2 | 両方 | 同一セッション内で再度トップページを開き直す | ローディング演出が再表示されない（sessionStorage による抑制） |
| 4-3 | 両方 | トップページをゆっくりスクロールする | 7 シーン（Diary 文字形 → グラフ → 1000+ → CTA 等）が `#track` のスクロール駆動でデスクトップと同じ順に切り替わり、途中で飛んだり止まったりしない |
| 4-4 | 両方 | 演出中・演出後にスクロール・タップ操作を行う | 引っかかりなく操作でき、体感 fps が保たれている（モバイルはパーティクル数・devicePixelRatio を軽量化） |
| 4-5 | 両方 | 演出を数分表示させたままにする | 端末が異常に熱くなっていない |
| 4-6 | iOS Safari | 設定 > アクセシビリティ > 動作 > 視差効果を減らす、を ON にしてトップページを開きスクロールする | 演出が動かず Diary の静止形のみ表示される（`prefers-reduced-motion: reduce`） |
| 4-7 | Android Chrome | OS のアニメーション削減設定を ON にしてトップページを開きスクロールする | 同上（静止形のみ） |
| 4-8 | 両方 | 上記の設定を OFF に戻す | 通常どおりスクロール駆動演出が動く |
