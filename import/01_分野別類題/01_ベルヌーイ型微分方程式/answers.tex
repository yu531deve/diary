\daimon{【解法】ベルヌーイ型微分方程式の解き方と導出}

\noindent
ベルヌーイ型微分方程式とは、次の形の1階微分方程式である（$n \neq 0, 1$）。
\[
\frac{dy}{dx} + P(x)\,y = Q(x)\,y^{n}
\]
両辺を $y^{n}$ で割ると
\[
y^{-n}\frac{dy}{dx} + P(x)\,y^{1-n} = Q(x)
\]
ここで $u = y^{1-n}$ とおくと $\dfrac{du}{dx} = (1-n)\,y^{-n}\dfrac{dy}{dx}$ であるから、上式は
\[
\frac{1}{1-n}\frac{du}{dx} + P(x)\,u = Q(x)
\quad\Longleftrightarrow\quad
\frac{du}{dx} + (1-n)P(x)\,u = (1-n)Q(x)
\]
という $u$ についての1階線形微分方程式に帰着する。これを積分因子 $\mu(x) = \exp\left((1-n)\displaystyle\int P(x)\,dx\right)$ を用いて解き、最後に $u = y^{1-n}$ を戻せば一般解が得られる。

\clearpage
\begin{mondaiboxS}{問1}
$\dfrac{dy}{dx} + \dfrac{y}{x} = x\,y^{2}$ の一般解を求めよ。
\end{mondaiboxS}
\kaitou
$n = 2$ のベルヌーイ型。両辺を $y^{2}$ で割ると
\[
y^{-2}\frac{dy}{dx} + \frac{1}{x}\,y^{-1} = x
\]
$u = y^{-1}$ とおくと $\dfrac{du}{dx} = -y^{-2}\dfrac{dy}{dx}$ より
\[
-\frac{du}{dx} + \frac{u}{x} = x
\quad\Longleftrightarrow\quad
\frac{du}{dx} - \frac{u}{x} = -x
\]
積分因子は $\mu = \exp\left(-\displaystyle\int \frac{dx}{x}\right) = \dfrac{1}{x}$ であるから
\[
\frac{d}{dx}\left(\frac{u}{x}\right) = -1
\quad\Longrightarrow\quad
\frac{u}{x} = -x + C
\quad\Longrightarrow\quad
u = Cx - x^{2}
\]
$u = y^{-1}$ を戻して
\[
\boxed{\; y = \frac{1}{Cx - x^{2}} \;}
\qquad (C \text{ は任意定数})
\]

\clearpage
\begin{mondaiboxS}{問2}
$\dfrac{dy}{dx} - y = e^{x}\,y^{3}$ の一般解を求めよ。
\end{mondaiboxS}
\kaitou
$n = 3$ のベルヌーイ型。両辺を $y^{3}$ で割ると
\[
y^{-3}\frac{dy}{dx} - y^{-2} = e^{x}
\]
$u = y^{-2}$ とおくと $\dfrac{du}{dx} = -2y^{-3}\dfrac{dy}{dx}$ より
\[
-\frac{1}{2}\frac{du}{dx} - u = e^{x}
\quad\Longleftrightarrow\quad
\frac{du}{dx} + 2u = -2e^{x}
\]
積分因子は $\mu = e^{2x}$ であるから
\[
\frac{d}{dx}\left(u\,e^{2x}\right) = -2e^{3x}
\quad\Longrightarrow\quad
u\,e^{2x} = -\frac{2}{3}e^{3x} + C
\quad\Longrightarrow\quad
u = Ce^{-2x} - \frac{2}{3}e^{x}
\]
$u = y^{-2}$ を戻して
\[
\boxed{\; \frac{1}{y^{2}} = Ce^{-2x} - \frac{2}{3}e^{x} \;}
\qquad (C \text{ は任意定数})
\]

\clearpage
\begin{mondaiboxS}{問3}
$\dfrac{dy}{dx} + 2xy = x\,y^{2}, \quad y(0) = 1$ を解け。
\end{mondaiboxS}
\kaitou
$n = 2$ のベルヌーイ型。両辺を $y^{2}$ で割り、$u = y^{-1}$（$\frac{du}{dx} = -y^{-2}\frac{dy}{dx}$）とおくと
\[
-\frac{du}{dx} + 2xu = x
\quad\Longleftrightarrow\quad
\frac{du}{dx} - 2xu = -x
\]
積分因子は $\mu = e^{-x^{2}}$ であるから
\[
\frac{d}{dx}\left(u\,e^{-x^{2}}\right) = -x\,e^{-x^{2}}
\quad\Longrightarrow\quad
u\,e^{-x^{2}} = \frac{1}{2}e^{-x^{2}} + C
\quad\Longrightarrow\quad
u = \frac{1}{2} + Ce^{x^{2}}
\]
初期条件 $y(0) = 1$ より $u(0) = 1$ であるから $C = \dfrac{1}{2}$。よって
\[
u = \frac{1 + e^{x^{2}}}{2}
\quad\Longrightarrow\quad
\boxed{\; y = \frac{2}{1 + e^{x^{2}}} \;}
\]
