# import/ — 既存問題の受け入れ窓口

Yu が過去に作成した問題(院試リポジトリ等)をフォルダごと投げ込む場所。**構造・命名は不問**。

## ルール(Yu 決定 2026-08-07)

- ここに置かれたファイルは**ビルド対象外・linter 対象外**(ビルド・lint は `content/` のみを走査する)
- .gitignore にはしない(コミットされ、リポジトリに保存される)
- ここから公開への道は「正規化パイプライン」(issue #57)のみ:
  1. ID 採番して `content/{id}/` に配置(連番・不変・欠番許容)
  2. diary.sty 前提(本文のみ形式)に書き換え
  3. meta.yaml を起こす(field/tags/difficulty は仮付けし、PR で Yu が確認)
  4. 取り込んだ元ファイルを import/ から削除
- 元の問題のレベルが Diary の想定利用者(大学受験生)と合うかの判断は Yu が PR 上で行う
