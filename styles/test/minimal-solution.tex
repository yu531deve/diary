\diarytitle{0001}{2 次関数の解と定積分}

$f(x) = x^2 - 3x + 2 = (x-1)(x-2)$ より、$f(x) = 0$ を満たす $x$ は $x = 1, 2$ である。

次に、定積分を計算する。
\[
  \int_{1}^{2} f(x)\,dx
  = \left[ \frac{x^3}{3} - \frac{3x^2}{2} + 2x \right]_{1}^{2}
  = -\frac{1}{6}
\]

したがって、求める値は $-\dfrac{1}{6}$ である。

% 全ページにフッターが焼き込まれることを検証するため、2 ページ目を追加する。
\newpage

続けて、不等式 $x^2 - 3x + 2 < 0$ を解く。$(x-1)(x-2) < 0$ より、$1 < x < 2$ である。
