SOLUTION / 0001

放物線と直線で囲まれた面積

まず自分で解いてから。必要な分だけ開いてください。

STEP 1 ヒント {{ hintLabel }}

交点は 2 式を連立して求まります。面積は「上の関数 − 下の関数」を交点間で積分します。どちらが上かは区間内の 1 点で確かめると確実です。

STEP 2 方針 {{ appLabel }}

交点の x 座標を α, β（α < β）とすると、求める面積は S = ∫αβ {(x+2) − x²} dx。
1/6 公式 (β−α)³ / 6 を使えば計算を短縮できます。

STEP 3 解答 {{ ansLabel }}
(1)

2 式を連立して x² = x + 2、すなわち x² − x − 2 = (x+1)(x−2) = 0。

x = −1 , 2
(2)

区間 −1 ≤ x ≤ 2 において x + 2 ≥ x² であるから

S = ∫−12 {(x+2) − x²} dx = [ x²/2 + 2x − x³/3 ]−12

1/6 公式を用いれば S = (2−(−1))³ / 6 = 27/6。

S = 9/2

計算量で殴らせない。手が止まる場所が一箇所だけある問題を目指しています。設定は短く、聞くことは明確に。誘導は最小限に留め、(1) が (2) の伏線になる構成を基本形にしています。
