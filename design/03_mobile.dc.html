放物線と直線で囲まれた面積

STEP 1 ヒント {{ hintSign }}

交点は 2 式を連立。面積は「上の関数 − 下の関数」を交点間で積分します。

STEP 2 方針 {{ appSign }}

1/6 公式 (β−α)³/6 を使えば計算が短縮できます。

STEP 3 解答 {{ ansLabel }}

連立して (x+1)(x−2) = 0

x = −1 , 2

区間 −1 ≤ x ≤ 2 で x + 2 ≥ x² より

S = ∫−12{(x+2) − x²}dx = 27/6
S = 9/2
