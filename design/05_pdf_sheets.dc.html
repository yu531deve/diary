放物線と直線で囲まれた面積

微分積分 / 定積分 | 数学Ⅱ | 難易度 | 目安 15 分

座標平面上において、放物線 C : y = x² と直線 ℓ : y = x + 2 を考える。

(1)

放物線 C と直線 ℓ の交点の x 座標をすべて求めよ。

(2)

放物線 C と直線 ℓ で囲まれた図形の面積 S を求めよ。

放物線と直線で囲まれた面積

(1) 交点の x 座標

2 式を連立して x² = x + 2。移項して整理すると

x² − x − 2 = (x + 1)(x − 2) = 0

よって、交点の x 座標は次の 2 つである。

x = −1 , 2
(2) 面積 S

区間 −1 ≤ x ≤ 2 において x + 2 ≥ x² が成り立つ。したがって求める面積は

S = ∫−12 {(x + 2) − x²} dx = [ x²/2 + 2x − x³/3 ]−12

あるいは 1/6 公式を用いて S = (β − α)³ / 6 = 3³ / 6 = 27 / 6 としてもよい。

S = 9/2
補足

1/6 公式は「2 次の係数 a の放物線と直線が α, β で交わるとき、囲む面積は |a|(β−α)³/6」。本問は a = 1 の場合。どちらが上かは区間内の 1 点（例えば x = 0）で確認すると確実。
