\diarytitle{0001}{実対称行列の直交対角化と二次形式・行列べき乗}

以下、$J$ を全成分が $1$ である $3 \times 3$ 行列とする。$A = I + J$ と
書けることに注意する（$I$ は単位行列）。この分解は各設問で繰り返し用いる。

\begin{enumerate}
  \item \textbf{固有値と固有空間.}

    まず $J$ の固有値を調べる。$\bm{u}_0 = (1,1,1)^{\top}$ に対して
    \[
      J\bm{u}_0 = (3,3,3)^{\top} = 3\bm{u}_0
    \]
    なので $3$ は $J$ の固有値である。一方、$x_1+x_2+x_3=0$ を満たす
    任意の $\bm{x}$ に対しては $J\bm{x} = \bm{0}$ となるので、この
    $2$ 次元部分空間 $\{\bm{x}\in\mathbb{R}^3 : x_1+x_2+x_3=0\}$ の各元は
    固有値 $0$ の固有ベクトルである。$\operatorname{tr} J = 3$ は固有値の総和に
    等しく、$3 = 3 + 0 + 0$ とちょうど合うので、$J$ の固有値は
    $3$（重複度 $1$）と $0$（重複度 $2$）ですべてである。

    $A = I + J$ であり、$J\bm{x} = \lambda\bm{x} \iff A\bm{x} = (1+\lambda)\bm{x}$
    が成り立つ（固有ベクトルは共通）ので、$A$ の固有値は
    \[
      \lambda_1 = 1+3 = 4 \quad (\text{重複度 } 1), \qquad
      \lambda_2 = 1+0 = 1 \quad (\text{重複度 } 2)
    \]
    である。$A$ は実対称行列であり、実対称行列は直交対角化可能で、
    相異なる固有値に属する固有空間は互いに直交し、各固有空間の次元は
    代数的重複度と一致する。

    固有値 $4$ の固有空間は $\operatorname{span}(\bm{u}_0)$ であり、正規化して
    \[
      \bm{p}_1 = \frac{1}{\sqrt{3}}(1,1,1)^{\top}.
    \]
    固有値 $1$ の固有空間は平面 $x_1+x_2+x_3=0$ である。この平面内で
    互いに直交する $2$ つのベクトルとして
    $\bm{v} = (1,-1,0)^{\top}$, $\bm{w} = (1,1,-2)^{\top}$ を取ると、
    いずれも $x_1+x_2+x_3=0$ を満たし（固有値 $1$ の固有空間に属し）、
    かつ $\bm{v}\cdot\bm{w} = 1 - 1 + 0 = 0$ で直交している。正規化すると
    \[
      \bm{p}_2 = \frac{1}{\sqrt{2}}(1,-1,0)^{\top}, \qquad
      \bm{p}_3 = \frac{1}{\sqrt{6}}(1,1,-2)^{\top}
    \]
    が固有値 $1$ の固有空間の正規直交基底である。

  \item \textbf{直交対角化.}

    前問の $\bm{p}_1,\bm{p}_2,\bm{p}_3$ を並べた行列
    \[
      P =
      \begin{pmatrix}
        \dfrac{1}{\sqrt{3}} & \dfrac{1}{\sqrt{2}} & \dfrac{1}{\sqrt{6}} \\[6pt]
        \dfrac{1}{\sqrt{3}} & -\dfrac{1}{\sqrt{2}} & \dfrac{1}{\sqrt{6}} \\[6pt]
        \dfrac{1}{\sqrt{3}} & 0 & -\dfrac{2}{\sqrt{6}}
      \end{pmatrix}
    \]
    は正規直交基底を列に並べた行列なので直交行列（$P^{\top}P=I$）である。
    実際、各列の長さが $1$ であること、および
    $\bm{p}_1\cdot\bm{p}_2 = 0$, $\bm{p}_1\cdot\bm{p}_3
    = \tfrac{1}{\sqrt{18}}(1+1-2)=0$, $\bm{p}_2\cdot\bm{p}_3=0$
    であることから確認できる。このとき
    \[
      P^{\top} A P = D, \qquad
      D = \begin{pmatrix} 4 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{pmatrix}
    \]
    が成り立つ。

  \item \textbf{二次形式の最大・最小.}

    $\bm{x} = P\bm{y}$ とおくと、$P$ は直交行列なので
    $\|\bm{y}\| = \|P^{\top}P\bm{y}\| = \|\bm{y}\|$、すなわち
    $\|\bm{y}\|=\|\bm{x}\|=1$ であり、
    \[
      \bm{x}^{\top}A\bm{x}
      = (P\bm{y})^{\top}A(P\bm{y})
      = \bm{y}^{\top}(P^{\top}AP)\bm{y}
      = \bm{y}^{\top}D\bm{y}
      = 4y_1^2+y_2^2+y_3^2.
    \]
    制約 $y_1^2+y_2^2+y_3^2=1$ の下で
    $4y_1^2+y_2^2+y_3^2 = 1+3y_1^2$ であり、$0\le y_1^2\le1$ だから、
    この式は $y_1^2=1$（すなわち $y_2=y_3=0$）のとき最大値 $4$ を、
    $y_1^2=0$（すなわち $y_2^2+y_3^2=1$）のとき最小値 $1$ をとる。
    これは、実対称行列の単位球上での二次形式の最大値・最小値が
    それぞれ最大固有値・最小固有値に一致するという一般的な事実
    （レイリー商の性質）の具体例になっている。

    最大値 $4$ を実現する $\bm{x}$ は $\bm{y}=(\pm1,0,0)^{\top}$ に対応する
    \[
      \bm{x} = \pm\bm{p}_1 = \pm\frac{1}{\sqrt3}(1,1,1)^{\top}
    \]
    の $2$ 点のみである。一方、最小値 $1$ を実現する $\bm{x}$ は
    $y_2^2+y_3^2=1$ を満たす任意の $(y_2,y_3)$ に対応する
    $\bm{x} = y_2\bm{p}_2+y_3\bm{p}_3$、すなわち固有値 $1$ の固有空間
    （平面 $x_1+x_2+x_3=0$）と単位球面の交わりである円周上のすべての点
    であり、一意には定まらない。これは固有値 $1$ の重複度が $2$ である
    ことの帰結であり、最大値の場合（固有値 $4$ が単純固有値なので
    実現点が符号を除き一意）と対比しておくとよい。

  \item \textbf{$A^n$ の成分.}

    \textbf{方法 1（対角化を用いる）.} $A = PDP^{\top}$ より
    $A^n = PD^nP^{\top}$ であり、$(A^n)_{ij} = \sum_{k=1}^{3} P_{ik}P_{jk}d_k^n$
    （$d_1=4,\ d_2=d_3=1$）と書ける。$P$ の第 $1$ 行、第 $2$ 行はそれぞれ
    $\left(\frac{1}{\sqrt3},\frac{1}{\sqrt2},\frac{1}{\sqrt6}\right)$,
    $\left(\frac{1}{\sqrt3},-\frac{1}{\sqrt2},\frac{1}{\sqrt6}\right)$
    なので
    \[
      (A^n)_{11}
      = \frac13\cdot4^n+\frac12\cdot1+\frac16\cdot1
      = \frac{4^n}{3}+\frac23 = \frac{4^n+2}{3},
    \]
    \[
      (A^n)_{12}
      = \frac13\cdot4^n-\frac12\cdot1+\frac16\cdot1
      = \frac{4^n}{3}-\frac13 = \frac{4^n-1}{3}.
    \]

    \textbf{方法 2（射影分解を用いる別解）.} $P_1 := \frac13 J$ は
    $\operatorname{span}(\bm{u}_0)$ への直交射影である。実際、$J^2=3J$
    （$J$ の固有値が $3,0,0$ であることから、あるいは
    $J^2_{ij}=\sum_k J_{ik}J_{kj}=3$ という直接の成分計算からも従う）より
    \[
      P_1^2 = \frac19 J^2 = \frac19(3J) = \frac13 J = P_1
    \]
    となってべき等であり、$J$（したがって $P_1$）は対称行列でもあるから
    $P_1$ は直交射影である。$P_1$ の像は $\operatorname{span}(\bm{u}_0)$、
    核は $\{x_1+x_2+x_3=0\}$ に一致する。
    $A = I+J = I+3P_1 = (I-P_1)+4P_1$ であり、$P_1$ と $I-P_1$ は互いに
    直交する射影（$P_1(I-P_1)=P_1-P_1^2=0$、いずれもべき等）なので、
    正の整数 $n$ に対して二項展開の交差項がすべて消え、
    \[
      A^n = \bigl[(I-P_1)+4P_1\bigr]^n = (I-P_1)^n+4^nP_1^n
      = (I-P_1)+4^nP_1 = I+(4^n-1)P_1 = I+\frac{4^n-1}{3}J
    \]
    が成り立つ（べき等射影は $(I-P_1)^n=I-P_1$, $P_1^n=P_1$ を満たす）。
    成分で書くと対角成分は $1+\frac{4^n-1}{3}$、非対角成分は
    $\frac{4^n-1}{3}$ であるから
    \[
      (A^n)_{11} = 1+\frac{4^n-1}{3} = \frac{4^n+2}{3}, \qquad
      (A^n)_{12} = \frac{4^n-1}{3}
    \]
    となり、方法 1 の結果と一致する。$n=1$ で代入すると
    $(A)_{11}=\frac{4+2}{3}=2$, $(A)_{12}=\frac{4-1}{3}=1$ となって
    実際の $A$ の成分と一致することも検算として確認できる。

    以上より
    \[
      (A^n)_{11} = \frac{4^n+2}{3}, \qquad (A^n)_{12} = \frac{4^n-1}{3}
    \]
    である。
\end{enumerate}
