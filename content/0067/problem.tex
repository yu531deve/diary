\diarytitle{0067}{ラプラス方程式の境界値問題（円板領域、極座標での有界解）}

半径 $3$ の円板 $D = \{(r,\theta) \mid 0 \le r < 3\}$ における次の境界値問題を、極座標形式のラプラス方程式
\[
u_{rr} + \frac{1}{r}u_r + \frac{1}{r^2}u_{\theta\theta} = 0
\]
のもとで、変数分離法を用いて解け。ただし $u$ は円板内で有界とする。
\[
u(3, \theta) = 4 + 6\cos\theta - 3\sin 2\theta \qquad (0 \le \theta < 2\pi)
\]
