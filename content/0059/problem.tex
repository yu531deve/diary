\diarytitle{0059}{波動方程式の一般解（ダランベールの解の導出）}

次の波動方程式（無限区間）に関する問いに答えよ。
\[
\frac{\partial^{2} u}{\partial t^{2}} = c^{2}\frac{\partial^{2} u}{\partial x^{2}} \qquad (-\infty < x < \infty,\ t > 0)
\]
特性変数 $\xi = x - ct$, $\eta = x + ct$ を用いて変数変換を行い、一般解が
\[
u(x,t) = f(x-ct) + g(x+ct)
\]
の形で表されることを導け（$f$, $g$ は任意の $C^{2}$ 級関数）。
